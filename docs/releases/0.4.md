## Overlap 0.4

### New
- **Mood boards** — turn a query into a free-form canvas in its own window. Drag, resize, align and snap tiles; add notes, labels and boxes; pull a color palette from the images; export as an image or a folder. **Refresh** pulls in new matches for the board's query.
- **Connected services** — a new plugin type for external image services. Browse, import and sync collections, pick single items, send files, link a board to a collection, or publish a board as a new one. Ships with **Are.na** (*Sources ▸ Connected Services…*, ⌘⇧Y):
  - Browse your feed, the channels you follow, your own channels, or any channel by link. Search is available on Premium.
  - Imported blocks become real files in `<library>/Are.na/<Channel>/`, tagged `arena/<Channel>`.
  - Edit a channel's title, description and visibility from Overlap.
  - Your access token stays in the keychain. Hidden and vault files are never sent, and Overlap asks before anything becomes more visible.
- **Encrypted vault for hidden tags** — hidden files can live in an AES-256 disk image, unlocked with Touch ID or a password, with auto-lock.
- **Plugins menu** is now grouped into Connected Services, Tag Suggestions, and Search.

### Fixed
- Tag suggestions now pick up tag changes in your library. Before, the suggestion model kept an old list of your tags.
- The vault no longer shows “.DS_Store could not be moved…” errors.
- Thumbnails stay fast after locking or unlocking hidden. Locking now clears only the vault's thumbnails; to clear every thumbnail cache, turn on *Privacy ▸ Clear all thumbnail caches on lock*.

### Removed
- The demo plugins `folderkind` and `mockcluster`.
