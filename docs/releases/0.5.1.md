## Overlap 0.5.1

### New
- **Endless Explore feed.** Next batch (E, Space past the last image, or the button) now adds to the bottom of the grid instead of replacing it, and scrolling to the end loads more on its own. Earlier batches stay a scroll up, with a thin divider where each one starts. Changing the tags, the folder or resetting starts a fresh feed.
- **Search, suggestions and Explore for hidden files.** With the encrypted vault on, a new switch in Privacy lets hidden files take part. They get their own plugin index, stored inside the vault and readable only while revealed, and their own Explore profile. Only plugins marked local are used; online services never see hidden files. Turning it off deletes the hidden index and profile.
- **Undo and redo for queries.** Adding, excluding or removing a circle, painting regions, adding or removing a diagram, AND/OR and match mode changes are all undoable with ⌘Z / ⌘⇧Z.
- **Remove a circle in one click.** Hover a diagram and an ⓧ appears beside each circle's name.

### Changed
- **Tastes stay separate.** Explore no longer squeezes your likes into six tastes by merging unrelated ones, which could build one huge catch-all taste. Every taste is tracked; batches draw from the strongest six, and the sidebar shows how many more are forming.
- **A new, empty diagram offers every tag** in the tag map, not just tags from the other diagrams' results, and opens at the top level of the map.
- **Duplicates and hidden files.** Hidden images are compared only with each other, show a lock in the Duplicates window, and leave it when you lock. "Not Duplicates" for hidden pairs is kept in the vault.
- **Hidden files stay hidden** in more places: mood boards made from hidden results are stored encrypted, hidden tiles drag only within Overlap, and exporting a query that includes hidden files asks first (skipping them is the default).

### Plugins
- New manifest key `"local": true`: the plugin promises it never sends data off the Mac. Only local plugins run on hidden files. Overlap CLIP and Overlap Suggest declare it.
- New environment variables `OVERLAP_PLUGIN_SHARED_CACHE`, `OVERLAP_PLUGIN_CACHE_STRICT` and `OVERLAP_PLUGIN_CACHE_VOLUME`. See docs/PLUGINS.md and the Overlap CLIP README.
